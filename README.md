#  To-Do List Web App

A simple and interactive **To-Do List application** built using **HTML, CSS, and JavaScript**.
It allows users to add, delete, and mark tasks as completed, with data saved in **localStorage** so tasks remain even after page reload.

---

## 🚀 Features

*  Add new tasks
*  Delete tasks
*  Mark tasks as completed (toggle strike-through)
*  Persistent data using **LocalStorage**
*  Clean and modern UI design
*  Responsive layout

---

##  Technologies Used

* HTML5
* CSS3
* JavaScript
